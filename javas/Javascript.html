HTML에서 자바스크립트를 연결하는 3가지 방법

인라인(Inline) · 내부(Internal) · 외부(External) 방식 비교

HTML 문서에 자바스크립트를 넣는 방법은 크게 세 가지로 나뉩니다.

  • 인라인(Inline) — HTML 태그의 속성 안에 직접 코드를 작성
  • 내부(Internal / Embedded) — HTML 문서 안에 <script> 태그로 작성
  • 외부(External) — 별도의 .js 파일을 만들어 <script src="...">로 불러오기
방법 1

인라인(Inline) 방식

HTML 요소의 이벤트 속성(예: onclick, onmouseover)에 자바스크립트 코드를 직접 적는 방식입니다.

index.html
<button onclick="alert('안녕하세요!')">
  클릭해보세요
</button>

<img src="logo.png" onmouseover="this.style.opacity='0.5'"
     onmouseout="this.style.opacity='1'">
장점 간단한 동작을 빠르게 테스트할 때 편리함
단점 HTML과 로직이 뒤섞여 유지보수 어려움, 코드 재사용 불가, 규모가 커지면 지저분해짐
방법 2

내부(Internal) 방식

HTML 문서 내부에 <script></script> 태그를 사용해서 자바스크립트 코드를 작성하는 방식입니다. 보통 <head> 또는 </body> 직전에 넣습니다.

index.html
<!DOCTYPE html>
<html>
<head>
  <title>내부 스크립트 예제</title>
</head>
<body>
  <h1 id="title">원래 제목</h1>
  <button id="btn">제목 바꾸기</button>

  <script>
    const btn = document.getElementById('btn');
    btn.addEventListener('click', () => {
      document.getElementById('title').textContent = '제목이 바뀌었습니다!';
    });
  </script>
</body>
</html>
장점 HTML 파일 하나로 관리 가능, 소규모 페이지에 적합
단점 여러 HTML 페이지에서 같은 코드를 재사용하기 어려움, 파일이 길어지면 가독성 저하
방법 3

외부(External) 방식

자바스크립트 코드를 별도의 .js 파일로 분리하고, <script src="파일경로">로 불러오는 방식입니다. 실무에서 가장 많이 사용합니다.

index.html
<!DOCTYPE html>
<html>
<head>
  <title>외부 스크립트 예제</title>
</head>
<body>
  <h1 id="title">원래 제목</h1>
  <button id="btn">제목 바꾸기</button>

  <!-- body 마지막에 위치시키는 것이 일반적 -->
  <script src="script.js"></script>
</body>
</html>
script.js
const btn = document.getElementById('btn');
btn.addEventListener('click', () => {
  document.getElementById('title').textContent = '제목이 바뀌었습니다!';
});
장점 HTML과 JS 분리로 가독성·유지보수성 향상, 여러 페이지에서 재사용 가능, 브라우저 캐싱으로 성능 향상
단점 파일이 여러 개로 늘어남, 경로 설정이 틀리면 스크립트가 동작하지 않음

한눈에 비교

방식 코드 작성 위치 주요 사용 상황
인라인 HTML 태그의 속성 안 간단한 테스트, 아주 짧은 이벤트 처리
내부 HTML 문서 안 <script> 태그 단일 페이지 소규모 프로젝트
외부 별도의 .js 파일 실무 프로젝트, 여러 페이지 공유, 유지보수 중요할 때
Tip. 실무에서는 코드 분리와 재사용성 때문에 외부 방식을 가장 권장합니다.
