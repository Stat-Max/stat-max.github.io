Math 객체 메소드 1

각 함수는 숫자를 변환하거나 방향을 계산하는 역할을 합니다. 그래프 위를 점이 움직이며 개념을 더 쉽게 이해할 수 있습니다.

abs(x)

음수를 양수로 바꾸어 크기만 비교할 때 사용합니다.

Math.abs(x)
결과: 0

acos(x)

x의 아크코사인을 계산해 각도를 구합니다. x는 -1~1 사이여야 합니다.

Math.acos(x)
결과: 0

acosh(x)

x의 하이퍼볼릭 아크코사인으로, x가 1 이상일 때 의미가 있습니다.

Math.acosh(x)
결과: 0

asin(x)

x의 아크사인을 계산해 각도를 찾습니다. 범위는 -1부터 1입니다.

Math.asin(x)
결과: 0

asinh(x)

역쌍곡선 사인으로, 입력값을 각도로 바꾸는 함수입니다.

Math.asinh(x)
결과: 0

atan(x)

입력값의 각도를 계산하며, 값이 커질수록 90°에 가까워집니다.

Math.atan(x)
결과: 0

atan2(y, x)

점의 방향을 계산할 때 쓰며, x와 y의 상대 위치로 각도를 구합니다.

Math.atan2(y, x)
결과: 0

cbrt(x)

세제곱근을 구합니다. 음수도 자연스럽게 계산할 수 있습니다.

Math.cbrt(x)
결과: 0

ceil(x)

소수점이 있으면 올림해 정수로 만들고, 큰 값으로 이동합니다.

Math.ceil(x)
결과: 0
