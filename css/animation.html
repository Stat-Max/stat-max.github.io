CSS3 Animation 타임라인 가이드

[핵심요약] CSS3 애니메이션(Animation)

  1. 애니메이션(Animation): 요소의 위치, 크기, 색상, 회전 등을 시간에 따라 변화시키는 기능 (JavaScript 없이 구현 가능).
  2. 프레임(Frame): 애니메이션을 구성하는 하나의 정지 화면.
  3. 키 프레임(Key Frame): 사용자가 직접 지정하는 중요한 시점(시작, 중간, 끝)으로 @keyframes 규칙으로 정의.
  4. 중간 프레임(In-between): 브라우저가 키 프레임 사이를 자동 계산하여 생성 (인터폴레이션/트위닝).
  5. 기본 구성: 
    @keyframes 이름 {
  from { 시작 상태 }
  to   { 종료 상태 }
}
  6. 주요 속성: animation-name, animation-duration, animation-delay, animation-timing-function, animation-iteration-count, animation-direction, animation-fill-mode, animation-play-state
  7. 기억하기: Transition은 상태 변화(hover 등)가 있을 때 실행되지만, Animation은 자동 실행이 가능합니다.
