📌 CSS Transform (2D 변형) 핵심 요약

transform: HTML 요소에 2D/3D 변형 적용 (이동, 회전, 확대/축소, 기울이기 가능)

transform-origin: 변형의 기준점(중심) 설정

주요 메소드

  • translate(x, y) : x, y축 이동
  • translateX(n) : x축 이동
  • translateY(n) : y축 이동
  • scale(x, y) : 크기 확대/축소
  • scaleX(n) : x축 크기 변경
  • scaleY(n) : y축 크기 변경
  • rotate(angle) : 지정 각도만큼 회전
  • skew(x, y) : x, y축 기울이기
  • skewX(angle) : x축 기울이기
  • skewY(angle) : y축 기울이기
  • matrix(...) : 행렬을 이용한 복합 변형

Transform - translate() 예제

1. translate(100px, 200px) : 오른쪽 100px, 아래쪽 200px 이동
translate(100px, 200px)





2. translateX(150px) : 오른쪽으로 150px 이동
translateX(150px)

3. translateY(-50px) : 위쪽으로 50px 이동 (음수 값)
translateY(-50px)
