JavaScript String 메서드 설명서

문자열은 글자들의 연속된 데이터

JavaScript에서 문자열은 단순히 텍스트가 아니라, 각 글자가 인덱스 번호를 가지는 객체처럼 다룰 수 있습니다. 그래서 글자 하나를 꺼내거나, 위치를 찾거나, 일부를 자르거나, 대문자로 바꾸는 다양한 메서드를 사용할 수 있습니다.

"hello"
→
문자열 객체
→
h e l l o
문자열의 각 문자는 인덱스 번호를 갖습니다. 예를 들어 "hello"에서 첫 글자는 0번, 두 번째 글자는 1번입니다.

1. String 기본 속성

length

문자열의 글자 수를 알려줍니다.

예시: "JavaScript" → 0

prototype

새 객체에 공통으로 사용할 기능을 추가할 때 쓰입니다.

예시: 사용자 객체에 age 추가 → 0

constructor

어떤 생성자 함수로 만들어졌는지를 알려줍니다.

예시: 객체 생성자 확인 → ...

2. 문자열 메서드 사용법

charAt(index)

특정 위치의 문자를 한 글자만 꺼내옵니다.

예시: "hello".charAt(0) → -

charCodeAt(index)

문자의 유니코드 값을 숫자로 반환합니다.

예시: "A".charCodeAt(0) → -

concat(str)

문자열을 이어 붙입니다.

예시: "Java" + "Script" → -

indexOf(문자)

문자가 시작되는 위치를 왼쪽에서부터 찾습니다.

예시: "AI Software".indexOf("AI") → -

lastIndexOf(문자)

문자가 마지막으로 등장하는 위치를 찾습니다.

예시: "to to to".lastIndexOf("to") → -

replace(기존, 새값)

일부 문자를 다른 문자로 바꿉니다.

예시: "hello" → "Good Bye" → -

match(규칙)

문자열에서 조건에 맞는 문자를 찾는 데 사용합니다.

예시: "AI Software".match(/AI/) → -

search(문자)

문자가 어디에 있는지 위치 번호를 찾습니다.

예시: "Hello, AI".search("AI") → -

slice(start, end)

문자열의 원하는 구간을 잘라서 새로운 문자열을 반환합니다.

예시: "Software".slice(2, 6) → -

split(구분자)

문자열을 구분 기준으로 나누어 배열로 만듭니다.

예시: "A,B,C".split(",") → -

toUpperCase()

영문자를 모두 대문자로 바꿉니다.

예시: "hello".toUpperCase() → -

toString()

숫자나 객체를 문자열로 바꿉니다.

예시: 5678.toString() → -
