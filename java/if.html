JavaScript 조건문과 반복문

1. if else

조건이 참이면 if, 거짓이면 else 블록을 실행합니다.

if (score >= 60) {
	result = "합격";
} else {
	result = "불합격";
}

2. else if

여러 조건을 순서대로 검사할 때 사용합니다.

if (score >= 90) {
	grade = "A";
} else if (score >= 80) {
	grade = "B";
} else {
	grade = "C";
}

3. switch

값이 여러 선택지 중 하나와 일치하는지 확인합니다. 각 경우 끝에는 break를 사용합니다.

switch (day) {
	case 1:
		name = "월요일";
		break;
	case 2:
		name = "화요일";
		break;
	default:
		name = "해당 없음";
}

4. for

반복 횟수를 알고 있을 때 편리합니다. 아래 예제는 1부터 입력한 수까지 더합니다.

for (var i = 1; i <= number; i++) {
	sum += i;
}

5. while

조건이 참인 동안 반복합니다. 조건을 먼저 확인하므로 처음부터 거짓이면 한 번도 실행하지 않습니다.

var i = 1;
while (i <= 5) {
	output += i + " ";
	i++;
}

6. do while

먼저 한 번 실행한 뒤 조건을 확인하므로, 조건과 관계없이 최소 한 번은 실행합니다.

var i = 1;
do {
	output += i + " ";
	i++;
} while (i <= 5);
